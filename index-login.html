Gerencie suas tarefas facilmente

💡 Nota: O token fornecido é um token de integração. Para usar o widget, você precisa gerar um token de acesso pessoal do TickTick.
Para obter seu token:
1. Acesse TickTick.com
2. Vá em Configurações → Integrações
3. Clique em "Autorizar" e copie o token
